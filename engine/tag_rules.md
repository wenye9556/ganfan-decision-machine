# 标准菜名表打标规则（LLM初打 · 供子agent执行）

## 任务
读取分配给你的输入文件（JSON数组，每项：name/cat/spice/pricing/price/window），为每道菜产出打标对象，写入指定的输出文件（JSON数组）。菜名必须逐字保留（含(小份)/(中份)/(小)/(大)后缀），不得增删改字。

## 输出对象字段（全部必填）
- `name`: 菜名（逐字复制输入）
- `slots`: [主食, 荤蛋白, 素, 汤饮] 四个0/1。一碗荤面/荤饭= [1,1,0,0]；纯素粉面=[1,0,1,0]或[1,0,0,0]；一份荤菜(打菜)=[0,1,0,0]；素菜=[0,0,1,0]；汤/粥=[0,0,0,1]；饮品=[0,0,0,1]；含肉套餐SKU(汉堡套餐)=[1,1,0,1]；白饭=[1,0,0,0]；蛋类加料=[0,1,0,0]；豆制品加料=[0,0,1,0]；丸子类加料=[0,1,0,0]。总槽≤3，主食≤1、荤≤1、素≤1、汤饮≤1。
- `taboo`: 忌口/过敏原子集字符串，逗号分隔，只允许闭集值：猪/牛/羊/海鲜/蛋/奶/花生/芝麻/麸质/香菜/内脏；无则填 "—"。推断规则：名含 猪/肉(默认猪)/排骨/火腿/叉烧/扣肉/红烧肉/猪脚/猪杂/肥肠→猪；牛肉/牛腩/肥牛/牛杂/牛筋/牛丸→牛；羊肉/羔羊→羊；鱼/虾/蟹/鱿鱼/鲈→海鲜；蛋(鸡蛋/鹌鹑蛋/蛋类/蛋糕类)→蛋；芝士/奶/雪糕/冰淇淋/麦旋风/酸奶→奶；花生→花生；芝麻/麻酱→芝麻；面/面粉/麸/馄饨皮/饺子皮/肠粉(米)不麸质但面条类(面/拌面/拉面/意面)→麸质；香菜→香菜；内脏(猪杂/牛杂/肥肠/鸭胗/鸡杂/鸭血/肝/腰)→内脏(另加对应肉)。水产汤粉"鱼丸"→海鲜。多个用逗号。
- `cook`: 七值枚举：清蒸水煮/凉拌/少油炒/正常炒/爆炒过油/干煸/油炸。规则：汤/汤面/汤粉/水饺/蒸/白灼/煮→清蒸水煮；拌面/干拌/凉拌/凉皮→凉拌；烤(烤肉/烤猪/照烧/烧烤)→少油炒；煎(煎蛋/煎饼/香煎)→正常炒；炸(炸蛋/鸡排/酥/脆皮/天妇罗)→油炸；爆炒/辣炒/干锅/小炒→爆炒过油；其余炒菜→正常炒；粥/豆浆→清蒸水煮。盖饭浇头有肉汁→正常炒。拿不准选正常炒。
- `absorb`: 弱/中/强。油炸→强；茄子/豆角/土豆/豆制品/面筋→强或中(叶菜弱)；汤品/清蒸→弱；面食/米饭→中；肉类炒→中。拿不准选中。
- `recipe`: 主料构成，数组，每项 [组件名, 百分比]，百分比合计≈100（±5内）。组件名优先用下方组件库；若库里没有，用 ["新组件:kcal值,prot值", 百分比] 格式内联数值（如 ["新组件:180,8", 30]）。
- `conf`: "估算级"（默认）。仅麦当劳菜品用 "公示级"。
- `taste`: 甜/咸/酸/鲜/清淡 单值。甜品/雪糕/汤圆/八宝粥→甜；酸辣/酸笋/酸菜(突出酸)→酸；汤粉面/肉菜→咸或鲜；粥/清汤/清淡菜→清淡。
- `est_gram`: 每份克重估计(int)。参考：大碗汤粉面/饭 500、标准碗 450、小份/小碗 380、汉堡套餐SKU 600-750、单个汉堡 200、薯条(中) 110、饮品 300-500、雪糕/麦旋风 150-200、蛋类加料 45-60、丸子/串类 60-100、打菜荤菜 180、半荤 200、素菜 150、白饭 200、馍/饼 100-150、半只鸡 350、鸡架 200。loader要求∈[20,2000]。
- `kcal100_override` 与 `prot100_override`: 可选。仅当有把握的公开数值时填（如麦当劳官方公示：每100g换算值）；其余不填（由组件构成统一计算）。

## 麦当劳公示级特殊规则（pricing=套餐SKU 且 window=麦当劳）
- conf 必须为 "公示级"，slots 总和必须 ≥2（多槽断言）。
- 用你知道的麦当劳官方营养数据（每100g换算）：巨无霸~252kcal/11.8g、麦辣鸡腿堡~265/13、板烧~248/14、麦香鱼~240/11、薯条~320/4、可乐~43/0、麦旋风~200/4 等，填 kcal100_override/prot100_override；不确定的按组件构成算（面包~280/8、牛肉饼~250/20、鸡腿肉~215/27、生菜~15/1、酱~400/1）。
- taboo 注意：汉堡面包→麸质；奶制品→奶；鱼→海鲜。
