# AI B-roll 素材插槽（public/assets/gen/）

合作者用 AI 视频生成工具产出的 B-roll 素材放本目录，并在 `manifest.json` 里声明。
声明了对应插槽，成片该段背景自动换成视频（静音、cover 填充、叠与现片一致的暖色压暗罩）；
**manifest 为空数组 `[]` 时，成片与无 AI 素材版逐帧等价**。manifest 是构建期读取（import，非运行时 fetch），
改动后需重新渲染才生效。

## 插槽一览（五类）

| 插槽 slot | 成片时间轴 | 视频时长要求 | 段数 | 建议文件名 |
|---|---|---|---|---|
| `S1_BG` | 0–12s（S1 全段背景） | ≥ 12s | 1 段 | `S1_BG.mp4` |
| `S3_SUM` | 约 40.3–49s（S3 总结镜头背景） | ≥ 9s | 1 段 | `S3_SUM.mp4` |
| `S6_BG` | 约 84.5–103s（S6 全段底层循环 B-roll） | ≥ 18.5s | 1 段 | `S6_BG.mp4` |
| `S7_CAROUSEL` | 109–117s（S7 菜品轮播段背景） | ≥ 8s | **4 段各 ≥ 2.5s** | `S7_CAROUSEL.mp4`（自行拼接为一段） |

时长超过槽位会自动截断；不足会提前黑帧，务必 ≥ 槽位时长。

各插槽画面说明：

- `S1_BG`：S1 全段底层（压暗罩约 0.62），上面叠「会胖吗/太贵/719 道选择题」弹幕文字，画面须平静不抢戏
- `S3_SUM`：S3 总结镜头底（压暗罩约 0.55），前景是「想增肌，想省钱」四枚标签
- `S6_BG`：S6 全段底层循环 B-roll（压暗罩加厚至约 0.8，保证学生/后勤/团餐三张前景卡片可读）；视频不足 18.5s 时会截断，建议生成 ≥ 18.5s 或自行循环拼接补足
- `S7_CAROUSEL`：S7 轮播段底（压暗罩约 0.30，最亮的一槽），需 **4 段各 ≥ 2.5s** 的不同食物特写，自行拼接成一段 ≥ 8s 的 MP4 后放入

## 素材规格

- 1920×1080、30fps、H.264 MP4、**无音轨**（成片内静音播放）
- 恒定或轻微运动即可（Ken Burns/蒸汽/浇汁类），不要快速甩镜
- 成片会统一叠暖色压暗罩（S1 约 0.62 / S3 约 0.55 / S6 约 0.8 / S7 约 0.30），素材可稍亮

## manifest.json 格式

```json
[
  { "slot": "S1_BG", "file": "assets/gen/S1_BG.mp4" },
  { "slot": "S3_SUM", "file": "assets/gen/S3_SUM.mp4" },
  { "slot": "S6_BG", "file": "assets/gen/S6_BG.mp4" },
  { "slot": "S7_CAROUSEL", "file": "assets/gen/S7_CAROUSEL.mp4" }
]
```

- 只写要启用的插槽；`file` 相对 `public/` 目录
- 文件名约定与 slot 同名（`<slot>.mp4`），也可自定义，但 `file` 字段必须写对

## 提示词规范（创意红线）

- 统一口径：**画面内无任何文字/招牌/价签/菜单屏**——纯食物特写，暖色窗边自然光，浅景深，动态以 蒸汽/浇汁/拉丝 为主；生成后逐帧检查无伪文字（模型乱码假字一律重生成再用）
- 若用 `photos/B-W04_麻辣香锅.jpg` 做**图生视频**首帧（B-W04 等含屏照片同理）：**必须先裁到食物区域**，避开画面里的菜单屏文字
